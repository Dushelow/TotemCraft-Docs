# TotemVulcanAddon

Аддон TotemCraft к Vulcan (до 09.11.2026 назывался TotemGuard).

Базовый плагин: Vulcan 2.9.7. Сервер: Paper/Purpur 26.3, только стабильный API Paper (без NMS).

## Механики

**Наказание по экспериментальным проверкам** (`rules`). Vulcan сам не наказывает по экспериментальным
проверкам. Аддон выполняет команду наказания, когда VL проверки дошёл до порога: редкие ложные срабатывания
у честных игроков до порога не доходят. Одно наказание на игрока за запуск. На половине порога и при
наказании - уведомление тем, кто получает уведомления Vulcan (`alerts`), клик телепортирует к игроку.
Ключ правила - `проверка:тип` как в журнале Vulcan (`speed:e`). Порог подбирается по `violations.txt`:
заметно выше максимума у честных игроков.

Редкие события (запуск, половина порога, наказание) пишутся в `journal.log` в папке плагина.

## Команды и права

| Команда | Право | По умолчанию |
|---|---|---|
| `/totemvulcan` (`/totemguard`): правила и число наказанных | `totemguard.admin` | op |
| `/totemvulcan reload`: перечитать правила без перезапуска | `totemguard.admin` | op |
| не наказывать игрока | `totemguard.bypass` | никто |

Права называются как у прежнего TotemGuard.

## Настройка

Всё в `config.yml`: у каждой механики свой раздел с `enabled: true/false` и комментариями, тексты сообщений там же (цвета через `&`). После правки нужен перезапуск сервера.

## Сборка

Нужны JDK 21+ и Maven, либо Docker:

```
docker run --rm -v m2cache:/root/.m2 -v "$PWD:/src" -w /src maven:3.9-eclipse-temurin-25 mvn -q -B package
```

Готовый jar: `target/TotemVulcanAddon-<версия>.jar`.

API базовых плагинов в наш jar не входят, при сборке берутся из папки `lib/` (в git не кладём, скопировать с сервера):

| Файл | Откуда (папка plugins/ сервера) |
|---|---|
| `lib/vulcan-api.jar` | Vulcan-*.jar (купленный, в репозиторий не кладём) |

## Установка

Положить jar в `plugins/`, старую версию убрать из папки (не держать рядом), перезапустить сервер.
Перезагрузка плагина на лету не поддерживается. При первом запуске создаётся `plugins/TotemVulcanAddon/config.yml`.
