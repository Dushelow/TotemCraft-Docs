# TotemEssentialsAddon

Аддон TotemCraft к EssentialsChat. Сам ближний чат (радиус, формат, приставку `[Рядом]`) делает Essentials, аддон только управляет режимом игрока.

Базовый плагин: EssentialsX и EssentialsChat 2.22. Сервер: Paper/Purpur 26.3, только стабильный API Paper (без NMS).

## Механики

**Ближний чат** (`local-chat`). `!текст` и `/l текст` - одно сообщение рядом, `/g текст` - одно сообщение всем
(даже из режима «рядом»), `/l` и `/g` без текста переключают режим. По умолчанию все пишут в общий
(`shout-default: true` в Essentials). `/l` занята в AuthMe как `/login`: до входа наша `/l` передаёт её
в AuthMe, после входа слово, совпадающее с паролем игрока, в чат не уходит. Обработчик `!` должен стоять
раньше EssentialsChat, поэтому в `plugin.yml` есть `loadbefore: [EssentialsChat]`.

**«Рядом никого нет»** (`no-one-nearby`). Если ближнее сообщение никто не услышал, игрок видит строку,
не чаще раза в `cooldown-seconds`. Наблюдатели и невидимые админы слушателями не считаются.
В Essentials `localNoOne` должен быть пустым.

**Ближнее не уходит в Discord** (`discord-filter`). DiscordSRV не знает про ближний чат и пересылал бы его
в общий канал. Без DiscordSRV пропускается.

**Строка слежки** (`spy-format-fix`). Убирает лишнее `</gray>` после ника в строке слежки за ближним чатом.

## Команды и права

| Команда | Право | По умолчанию |
|---|---|---|
| `/l [текст]` (`/local`) | `clantagview.local` | все |
| `/g [текст]` (`/global`) | `clantagview.local` | все |

Право называется как у прежнего плагина ClanTagView, где раньше жил ближний чат.

## Настройка

Всё в `config.yml`: у каждой механики свой раздел с `enabled: true/false` и комментариями, тексты сообщений там же (цвета через `&`). После правки нужен перезапуск сервера.

## Сборка

Нужны JDK 21+ и Maven, либо Docker:

```
docker run --rm -v m2cache:/root/.m2 -v "$PWD:/src" -w /src maven:3.9-eclipse-temurin-25 mvn -q -B package
```

Готовый jar: `target/TotemEssentialsAddon-<версия>.jar`.

API базовых плагинов в наш jar не входят, при сборке берутся из папки `lib/` (в git не кладём, скопировать с сервера):

| Файл | Откуда (папка plugins/ сервера) |
|---|---|
| `lib/essentials.jar` | EssentialsX-2.22.*.jar |
| `lib/authme.jar` | AuthMe-*.jar (на сервере необязателен) |
| `lib/discordsrv.jar` | DiscordSRV-*.jar (на сервере необязателен) |

## Установка

Положить jar в `plugins/`, старую версию убрать из папки (не держать рядом), перезапустить сервер.
Перезагрузка плагина на лету не поддерживается. При первом запуске создаётся `plugins/TotemEssentialsAddon/config.yml`.
