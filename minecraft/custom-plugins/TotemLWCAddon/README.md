# TotemLWCAddon

Аддон TotemCraft к LWC.

Базовый плагин: LWC 2.5.0. Сервер: Paper/Purpur 26.3, только стабильный API Paper (без NMS).

## Механики

**`/autolock`** (`autolock`). Игрок включает постоянный автоприват: всё из списка `blocks`, что он ставит,
сразу приватится типом `protection-type` (по умолчанию `donation`, на сервере «защищенный от кражи»:
класть может любой, брать только владелец). По умолчанию это сундуки, сундуки-ловушки, все медные сундуки
и бочки, как старый автоприват LWC до 26.3. Приват создаётся через событие LWC, поэтому работают лимиты
приватов; блок должен быть разрешён в `plugins/LWC/core.yml`. Вторая половина двойного сундука отдельного
привата не получает. Кто включил режим, хранится в `autolock-players.txt`.

**Сообщение у чужого «защищенного от кражи»** (`donation-notice`). LWC молча не даёт брать вещи из чужого
`donation`-контейнера. Аддон пишет игроку то же, что LWC пишет у обычного привата
(`protection.general.locked.private`: «Сундук принадлежит другому игроку.»), не чаще раза в `cooldown-seconds`.
Реагирует только на клики, которые LWC уже отменил.

## Команды и права

| Команда | Право | По умолчанию |
|---|---|---|
| `/autolock` | `autolock.use` | все |

Право называется как у прежнего плагина AutoLock, чтобы ничего не перевыдавать.

## Настройка

Всё в `config.yml`: у каждой механики свой раздел с `enabled: true/false` и комментариями, тексты сообщений там же (цвета через `&`). После правки нужен перезапуск сервера.

## Сборка

Нужны JDK 21+ и Maven, либо Docker:

```
docker run --rm -v m2cache:/root/.m2 -v "$PWD:/src" -w /src maven:3.9-eclipse-temurin-25 mvn -q -B package
```

Готовый jar: `target/TotemLWCAddon-<версия>.jar`.

API базовых плагинов в наш jar не входят, при сборке берутся из папки `lib/` (в git не кладём, скопировать с сервера):

| Файл | Откуда (папка plugins/ сервера) |
|---|---|
| `lib/lwc.jar` | LWC-Paper-2.5.0.jar |

## Установка

Положить jar в `plugins/`, старую версию убрать из папки (не держать рядом), перезапустить сервер.
Перезагрузка плагина на лету не поддерживается. При первом запуске создаётся `plugins/TotemLWCAddon/config.yml`.
