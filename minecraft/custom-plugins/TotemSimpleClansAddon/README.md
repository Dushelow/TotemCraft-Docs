# TotemSimpleClansAddon

Аддон TotemCraft к SimpleClans.

Базовый плагин: SimpleClans 2.19. Сервер: Paper/Purpur 26.3, только стабильный API Paper (без NMS).

## Механики

**Теги кланов только для клановых** (`clan-tags`). Тег клана перед ником в чате видят только игроки в
кланах и те, у кого есть право `see-permission` (по умолчанию `clantagview.see`). Остальные видят строку без
тега, консоль и журнал сервера видят всегда. Тег добавляется отдельно для каждого получателя штатным
механизмом Paper (`ChatRenderer`), пакеты не трогаются. В формате чата Essentials метки `{clan}` быть не
должно. Если строка начинается с приставки из `tag-after-prefixes` (`[Рядом] `), тег ставится после неё.

## Права

| Право | По умолчанию |
|---|---|
| `clantagview.see` | op (на сервере выдано в LuckPerms) |

Право называется как у прежнего плагина ClanTagView: в LuckPerms оно уже выдано.

## Настройка

Всё в `config.yml`: у каждой механики свой раздел с `enabled: true/false` и комментариями, тексты сообщений там же (цвета через `&`). После правки нужен перезапуск сервера.

## Сборка

Нужны JDK 21+ и Maven, либо Docker:

```
docker run --rm -v m2cache:/root/.m2 -v "$PWD:/src" -w /src maven:3.9-eclipse-temurin-25 mvn -q -B package
```

Готовый jar: `target/TotemSimpleClansAddon-<версия>.jar`.

API базовых плагинов в наш jar не входят, при сборке берутся из папки `lib/` (в git не кладём, скопировать с сервера):

| Файл | Откуда (папка plugins/ сервера) |
|---|---|
| `lib/simpleclans.jar` | SimpleClans.jar |

## Установка

Положить jar в `plugins/`, старую версию убрать из папки (не держать рядом), перезапустить сервер.
Перезагрузка плагина на лету не поддерживается. При первом запуске создаётся `plugins/TotemSimpleClansAddon/config.yml`.
