# TotemAdvancedBanX

Своя сборка AdvancedBanX 3.1.0 (автор забросил плагин, исходный репозиторий удалён). Версия `3.1.0-totem1`.

Проблема: на Paper 26.x AdvancedBanX молча не показывает ни одного сообщения (ни «забанен», ни «уже в бане»,
ни уведомления в чате, ни `/check`), хотя баны записываются. Встроенная в его jar библиотека
adventure-platform-bukkit не умеет 26.x.

Исправление: в jar подменён интерфейс `net.kyori.adventure.platform.bukkit.BukkitAudiences` (AdvancedBanX
вызывает только `create`, `sender`, `close`) на свою реализацию, которая отправляет сообщение обычным текстом
с цветами через `CommandSender.sendMessage(String)`. Остальной плагин и база банов не тронуты.

Сборка: положить исходный `AdvancedBanX-3.1.0.jar` в `lib/`, скомпилировать `src/` с classpath из этого jar
и paper-api, заменить классы в копии jar, в `plugin.yml` версия `3.1.0-totem1` (так сделано 14.11.2026).
Проверено на стенде: «успешно забанен», «уже забанен», карточка `/check`.
