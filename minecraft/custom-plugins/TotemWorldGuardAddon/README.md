# TotemWorldGuardAddon

Аддон TotemCraft к WorldGuard: правила регионов, которых нет среди его флагов. Регионы задаются названиями (в любом мире).

Базовый плагин: WorldGuard 7.0.21 и WorldEdit 7.4.6. Сервер: Paper/Purpur 26.3, только стабильный API Paper (без NMS).

## Механики

**Без огня от огненных шаров** (`no-fireball-fire`). Шары всполохов, гастов и заряды из раздатчиков не
поджигают блоки в регионах. Урон и поджог игроков и мобов остаются. Флаг WorldGuard `ghast-fireball deny`
не подходит: он отменяет и урон от шаров по игрокам.

**Мобы без урона от шипов** (`no-thorns-damage`). Выбранные мобы (сейчас всполохи) в регионах не получают
урон от шипов на броне игроков.

**Граница зоны вайпа** (`wipe-border`). Сообщения, когда игрок пересекает квадрат ±`radius` в мире
(пешком, на транспорте, телепортом): заголовок и строка при выходе, строка при возвращении. Переход в другой
мир сообщения не даёт, кроме попадания сразу за границу. Раньше это были `greeting`/`farewell` региона
`world_core`, но WorldGuard показывал их после каждого портала. Подробнее:
`docs/gameplay/World Core and Wipe Zone.md`.

`debug: true` пишет в журнал каждую отмену поджога и урон по мобам из `no-thorns-damage` в регионах.

Команд и прав нет.

## Настройка

Всё в `config.yml`: у каждой механики свой раздел с `enabled: true/false` и комментариями, тексты сообщений там же (цвета через `&`). После правки нужен перезапуск сервера.

## Сборка

Нужны JDK 21+ и Maven, либо Docker:

```
docker run --rm -v m2cache:/root/.m2 -v "$PWD:/src" -w /src maven:3.9-eclipse-temurin-25 mvn -q -B package
```

Готовый jar: `target/TotemWorldGuardAddon-<версия>.jar`.

API базовых плагинов в наш jar не входят, при сборке берутся из папки `lib/` (в git не кладём, скопировать с сервера):

| Файл | Откуда (папка plugins/ сервера) |
|---|---|
| `lib/worldguard.jar` | worldguard-bukkit-7.0.21.jar |
| `lib/worldedit.jar` | worldedit-bukkit-7.4.6.jar |

## Установка

Положить jar в `plugins/`, старую версию убрать из папки (не держать рядом), перезапустить сервер.
Перезагрузка плагина на лету не поддерживается. При первом запуске создаётся `plugins/TotemWorldGuardAddon/config.yml`.
