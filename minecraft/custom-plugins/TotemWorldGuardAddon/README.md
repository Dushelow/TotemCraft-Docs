# TotemWorldGuardAddon

Аддон TotemCraft к WorldGuard: правила регионов, которых нет среди его флагов. Регионы задаются названиями (в любом мире).

Базовый плагин: WorldGuard 7.0.21 и WorldEdit 7.4.6. Сервер: Paper/Purpur 26.3, только стабильный API Paper (без NMS).

## Механики (с 2.0.0)

WorldGuard необязателен (`softdepend`): он нужен только правилам, у которых в `where` указаны регионы.
У каждой механики раздел `where` (миры и регионы, пусто - везде). Опечатка в названии региона видна в журнале.

**Временный огонь** (`temporary-fire`). Огонь, поставленный мобами из `sources` (всполохи, гасты) шаром или
взрывом шара, горит как обычно (игрок горит и получает урон), но через `burn-seconds` (60) гаснет сам, блоки под
ним не сгорают, дальше не ползёт. В 26.x источником поджога приходит сам моб, в старых версиях снаряд: учтены оба.

**Взрывы без разрушения** (`no-block-damage-explosions`). Взрывы мобов из `mobs` (гаст: его шар) не ломают блоки,
урон существам остаётся.

**Правила урона** (`damage-rules`, список именованных правил). Существа из `victims` не получают урон от мобов
из `from-mobs` (удар, снаряд, взрыв снаряда) или от причин из `from-causes` (thorns, fire, fire_tick, lava...)
в `where`, от `from-mobs` ещё и не загораются. Сейчас: `villagers-in-castle` (жители в замке от всполохов и гастов
и огня) и `blazes-no-thorns` (всполохи в замке от шипов). Быстрый путь: если тип существа не встречается
ни в одном правиле, событие отпускается сразу.

**Граница зоны вайпа** (`wipe-border`). Сообщения при пересечении квадрата ±`radius` вокруг центра границы
мира: шаг, транспорт, телепорт, вход в игру за границей. Переход между мирами сообщения не даёт.

## Команды

`/totemrules status` - что включено и сколько сработало; `/totemrules reload` - перечитать config.yml без
перезапуска. Право `totemrules.admin` (op).

## Настройка

Всё в `config.yml`: у каждой механики свой раздел с `enabled: true/false` и комментариями, тексты сообщений там же (цвета через `&`). После правки нужен перезапуск сервера.

## Сборка

Нужны JDK 21+ и Maven, либо Docker:

```
docker run --rm -v m2cache:/root/.m2 -v "$PWD:/src" -w /src maven:3.9-eclipse-temurin-25 mvn -q -B package
```

Готовый jar: `target/TotemWorldGuardAddon-<версия>.jar`.

API базовых плагинов в наш jar не входят, при сборке берутся из папки `lib/` (в git не кладём, скопировать с сервера):

| Файл | Откуда (папка plugins/ сервера) |
|---|---|
| `lib/worldguard.jar` | worldguard-bukkit-7.0.21.jar |
| `lib/worldedit.jar` | worldedit-bukkit-7.4.6.jar |

## Установка

Положить jar в `plugins/`, старую версию убрать из папки (не держать рядом), перезапустить сервер.
Перезагрузка плагина на лету не поддерживается. При первом запуске создаётся `plugins/TotemWorldGuardAddon/config.yml`.
