# Центр мира и зона обновления

Действует с перехода на 26.3 (ноябрь 2026).

## Для игроков

- **Центр мира**: квадрат от -10 000 до 10 000 по X и Z в обычном мире. Здесь мир не сбрасывается никогда.
- **Зона обновления**: от 10 000 до 11 000 блоков, дальше граница мира. При каждом переходе сервера на новую
  версию Minecraft эта зона стирается и генерируется заново, чтобы в ней появлялись новые биомы и постройки
  из обновлений. Всё построенное там будет удалено.
- Ад и Энд в эту механику не входят, их сбрасывает администрация отдельно.

При выходе из центра в чате появляется предупреждение «⚠ Вы покидаете центр мира», по центру экрана «⚠ Внимание! Зона вайпа»,
внутри центра в чате серая строка «Основной мир без вайпов (до 10.000 блоков)».

## Для администрации

**Регион WorldGuard `world_core`** в мире `2025`:

| Параметр | Значение |
|----------|----------|
| Границы | `-10000, -64, -10000` → `10000, 319, 10000` |
| `passthrough` | `allow`: регион никого не защищает и не мешает другим регионам и приватам |
| `greeting` | `&7Основной мир без вайпов (до 10.000 блоков)` |
| `farewell` | `&e⚠ Вы покидаете центр мира. &7Дальше 10.000 блоков территория обновляется с выходом новых версий: постройки будут удалены.` |
| `farewell-title` | `&c⚠ Внимание! Зона вайпа`. Только одна строка: длинный заголовок с подзаголовком не влезает на экран |
| Приоритет | 0 |

Регион добавляется скриптом `system/scripts/add_world_core.py` при остановленном сервере, отдельным блоком в
`regions.yml`. Не править этот файл регулярками целиком: так однажды на стенде затёрли флаги `__global__`.

**Незер и Энд**: WorldGuard считает переход в другой мир выходом из `world_core` и показал бы прощальное
сообщение. Он не повторяет его, если в новом месте действует тот же текст, поэтому на `__global__` Незера и
Энда стоят те же `farewell` и `farewell-title` (без `greeting`). Тексты задавать командой `/rg flag`, а не
правкой файла: WorldGuard сравнивает строки буквально, и `&` из файла не равно `§` после команды.

```
rg flag -w 2025_nether __global__ farewell <тот же текст>
rg flag -w 2025_nether __global__ farewell-title <тот же текст>
rg flag -w 2025_the_end __global__ farewell <тот же текст>
rg flag -w 2025_the_end __global__ farewell-title <тот же текст>
```

**Граница мира**: центр `0 0`, `worldborder set 22000` (упор на 11 000).

**Обрезка при переходе на новую версию**: после запуска нового ядра, до входа игроков, в консоли:

```
chunky world 2025
chunky shape square
chunky center 0 0
chunky radius 10000
chunky trim
chunky confirm
```

Обрезка необратима, поэтому делается только после вечного архива перехода (см. `docs/deployment/Version Upgrade Guide.md`).
Проверено на стенде в масштабе 1000/1500: удаление занимает секунды, на стыке центра и зоны виден шов рельефа, это нормально.
