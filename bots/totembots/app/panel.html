Новый бот

После добавления откройте у бота вкладку «На сервере»: там команды, которые надо один раз выполнить на сервере.

Сайты нейросетей (без ключа)

Бот думает через сайты по очереди: у одного лимит, проверка или сбой - сразу следующий. Войдите на нужные один раз. У каждого сайта два окна: окно бота (там работает программа, пока она занята - нажимать нельзя, листать можно) и моё окно (ваше, бот туда не заходит).

Проект Qwen

Чаты ботов и их память лежат в проекте «TotemCraft · боты» в вашем Qwen.

Нейросети по ключу (быстрее, без капч)

Ответ за 1-2 секунды вместо 5-10. Ключ бесплатный: «где взять», войти своим аккаунтом, создать ключ, вставить сюда. Ключи хранятся только на этом компьютере.

Порядок

Кого спрашивать первым, через запятую. Сайты: qwen, deepseekweb, kimiweb, glmweb, mistralweb, grokweb, chatgptweb, geminiweb, copilotweb. По ключу: gemini, groq, openrouter, deepseek.
