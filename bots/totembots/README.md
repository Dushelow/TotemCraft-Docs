# TotemBots

Программа для компьютера владельца: боты-игроки TotemCraft (mineflayer) с чатом через Qwen.
Запускается по желанию, пока выключена, ботов на сервере нет. Всё в одном окне: слева панель, справа chat.qwen.ai.

## Состояние (15.11.2026)

Готово окно и вход в Qwen. Google не пускает вход во встроенные окна («браузер небезопасен»), поэтому кнопка
«Войти через Chrome» запускает настоящий Chrome с отдельным профилем (`%APPDATA%/totembots/chrome-login`, основной
Chrome не трогается) и портом отладки 9333, ждёт входа, забирает куки chat.qwen.ai и `token` из localStorage в профиль
программы (`persist:qwen`) и закрывает Chrome. Проверено владельцем 15.11.

Дальше: мост к Qwen (вписать сообщение, дождаться ответа; образец - тренажёр в `naparnik/trainer`: прогрев через
`---`, свой чат на бота, ответ частями, задержка печати, «Повторить»), затем бот Alex на mineflayer (ходит за игроком,
болтает), панель ботов.

Правила ботов: на прямой вопрос «ты бот?» не врёт; без флирта; вещи владельца трогает только по приказам владельца
и выбранных людей; команд сервера нет.

## Запуск

```
npm install
npm start
```
