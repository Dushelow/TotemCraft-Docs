# TotemBots

Программа для компьютера владельца: боты-игроки TotemCraft (mineflayer) с чатом через Qwen.
Запускается по желанию, пока выключена, ботов на сервере нет. Всё в одном окне: слева панель, справа chat.qwen.ai.

## Состояние (15.11.2026)

Работает на стенде (tc-up, 26.3, Vulcan включён), проверено `test/qwen_e2e.js`: бот болтает через Qwen, по «иди за мной»
идёт компаньоном (держится в 2-3 блоках), по приказу из панели берёт из сундука и отдаёт игроку (128 шерсти дошли),
на прямой вопрос «ты бот?» отвечает честно. `test/body_test.js` - то же без Qwen.

Устройство:
- `app/main.js` - окно, панель, настройки `%APPDATA%/totembots/config.json` (адрес, хозяева, год рождения для Qwen, боты с паролями);
- `app/qwen-bridge.js` - chat.qwen.ai внутри окна: перехват потока ответа, ввод в поле, очередь, окно возраста;
- `app/brain.js` - прогрев чата, сообщение для Qwen (события + состояние), разбор JSON-ответа, права хозяев;
- `app/bot.js` - mineflayer + pathfinder: компаньон, goto/take/put/give/portal, плавный взгляд, еда, AuthMe;
- `app/chrome-login.js` - вход в Qwen через настоящий Chrome (Google не пускает во встроенное окно);
- `app/guard.js` - защита от мобов (идеи модулей Meteor KillAura/AutoArmor/AutoTotem, код свой): удар при полном откате,
  удар с разбега и шаг назад, нейтральных и игроков не трогает, от шипящего крипера отбегает, броня и тотем сами.
  Режим в панели: защищать / убегать к хозяину / не трогать. Проверка `test/guard_test.js`: три зомби убиты (железо,
  осталось 4-10 здоровья), зомби-пиглин цел, крипер убит или бот отбежал.

Особенности сервера, найденные на стенде:
- бот заходит клиентом 1.21.11 (ViaVersion), mineflayer не шлёт пакет `tick_end`, а сервер 1.21.2+ без него не применяет
  шаги: бот шлёт его каждый тик;
- AuthMe 6 спрашивает пароль окном до входа в мир (`authme:prejoin-login/submit`); пакет custom_click_action собирается
  вручную: длина + NBT без флага optional (описание в minecraft-data не подходит);
- регистрация в игре выключена (`reg_only`): аккаунт боту заводится из консоли `authme register <ник> <пароль>`;
- автор сообщения - по UUID отправителя (`messagestr`, позиция chat), текст без оформления.

Правила ботов: на прямой вопрос «ты бот?» не врёт; без флирта; действия только по приказам хозяев; блоки не ломает
и не ставит; команд сервера нет.

Шаг 1 плана (DESIGN.md) сделан 15.11: переподключение после кика (не при бане), после смерти бот сам идёт за вещами
и возвращается к хозяину, навыки `pickup`, `recover`, `harvest` (спелое - сломать, подобрать семена, посадить обратно;
ломает только урожай), режим и модель Qwen: болтовня «Быстро» (ответ ~4 с вместо 15-40), задания «Авто», запасные
модели при ошибке лимита. Проверки: `test/skills_test.js` (урожай 7 из 7 посажено, доски рядом целы, вещи у места
смерти собраны, после кика вернулся через 15 с), `test/qwen_e2e.js`.

Решение 15.11: позиций всех игроков у бота нет и не будет - иначе любой выспросит у него, где чья база. Бот знает
то, что видит сам, и места, которые назвал владелец.

Голос (15.11): `app/voice.js`, три способа озвучки по порядку (запасные включаются сами): Qwen «Read aloud» (голос из
настроек Qwen; звук берётся отладчиком Electron из ответа `/api/v2/tts/completions`: base64 PCM 24 кГц моно 16 бит,
вкладка Qwen заглушена, играем сами), Piper (нейросеть на компьютере, скачивается кнопкой в панели в
`%APPDATA%/totembots/piper`, голоса ru_RU denis/dmitri/ruslan/irina), голоса Windows (только колонки). Чтобы озвучка
не читала служебное, ответ Qwen теперь: реплика текстом + блок кода `{"actions": [...]}` (блок кода Qwen не читает,
проверено: 1,8 с звука на фразу). Проверено `test/qwen_e2e.js`: звук Qwen 0,6-2,8 с на реплику. Piper запущен ещё не был.

Окно «Which response do you prefer?»: программа выбирает первый вариант и берёт его текст со страницы.
Менеджер чатов в карточке бота: текущий, история (до 30), подписи, «Сделать текущим», ссылка на чат, «Прогреть заново».

Память и воля (15.11): `app/memory.js` - места, люди, факты, дневник каждого бота. Бот пополняет сам (Qwen шлёт
`remember`; тело само пишет смерти, найденные порталы, встречи), «тут» - координаты того, кто говорит. Когда тихо
(по умолчанию 4 мин), приходит `[тишина]`, и бот сам решает, чем заняться. Без хозяина можно только безопасное
(ходить, запоминать, урожай, подбирать). Сводка памяти - в сообщениях Qwen, когда изменилась.

Проект Qwen (`app/qwen-project.js`): программа сама создаёт проект «TotemCraft · боты» (память Project-only),
кладёт туда `totemcraft-memory.md` (заменяя прежний, не чаще раза в 10 минут), новые чаты ботов - внутри проекта.
Локальная копия памяти - `%APPDATA%/totembots/memory/` (килобайты). Тесты: свои настройки и память в `test/.data`,
свой проект «TotemCraft · тест» (TOTEMBOTS_CONFIG / TOTEMBOTS_MEMORY / TOTEMBOTS_PROJECT_NAME), настройки
владельца не трогают, при открытой программе владельца не запускаются.

Дальше: голос в Plasmo Voice (аддон на сервере), уши бота (аддон + Whisper), ответ в том же канале чата (общий, «[Рядом]», личка, клан), «запомни место».
