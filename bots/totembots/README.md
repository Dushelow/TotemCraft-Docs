# TotemBots

Программа для компьютера владельца: боты-игроки TotemCraft (mineflayer) с чатом через Qwen.
Запускается по желанию, пока выключена, ботов на сервере нет. Всё в одном окне: слева панель, справа chat.qwen.ai.

## Состояние (15.11.2026)

Работает на стенде (tc-up, 26.3, Vulcan включён), проверено `test/qwen_e2e.js`: бот болтает через Qwen, по «иди за мной»
идёт компаньоном (держится в 2-3 блоках), по приказу из панели берёт из сундука и отдаёт игроку (128 шерсти дошли),
на прямой вопрос «ты бот?» отвечает честно. `test/body_test.js` - то же без Qwen.

Устройство:
- `app/main.js` - окно, панель, настройки `%APPDATA%/totembots/config.json` (адрес, хозяева, год рождения для Qwen, боты с паролями);
- `app/qwen-bridge.js` - chat.qwen.ai внутри окна: перехват потока ответа, ввод в поле, очередь, окно возраста;
- `app/brain.js` - прогрев чата, сообщение для Qwen (события + состояние), разбор JSON-ответа, права хозяев;
- `app/bot.js` - mineflayer + pathfinder: компаньон, goto/take/put/give/portal, плавный взгляд, еда, AuthMe;
- `app/chrome-login.js` - вход в Qwen через настоящий Chrome (Google не пускает во встроенное окно).

Особенности сервера, найденные на стенде:
- бот заходит клиентом 1.21.11 (ViaVersion), mineflayer не шлёт пакет `tick_end`, а сервер 1.21.2+ без него не применяет
  шаги: бот шлёт его каждый тик;
- AuthMe 6 спрашивает пароль окном до входа в мир (`authme:prejoin-login/submit`); пакет custom_click_action собирается
  вручную: длина + NBT без флага optional (описание в minecraft-data не подходит);
- регистрация в игре выключена (`reg_only`): аккаунт боту заводится из консоли `authme register <ник> <пароль>`;
- автор сообщения - по UUID отправителя (`messagestr`, позиция chat), текст без оформления.

Правила ботов: на прямой вопрос «ты бот?» не врёт; без флирта; действия только по приказам хозяев; блоки не ломает
и не ставит; команд сервера нет.

Дальше: защита от мобов (на стенде ночью зомби убили бота), выбор быстрого режима Qwen (ответ 15-40 с), скин.
