# Что берём из Baritone и Meteor (сверка 15.11.2026)

Сделано и проверено на стенде (`test/matrix_test.js`, `skills_test`, `guard_test`, `body_test`, отметок Vulcan 0): всё,
что ниже помечено «делаем», кроме: сон (на стенде 26.3 нельзя сменить время суток - не проверен) и «удар от игрока
→ мозгу» (код есть, на стенде удары между игроками не проходят - не проверен). Воздух под водой: `bot.oxygenLevel`
в этой версии может не приходить, всплытие держится на «в воде без дела - прыжок».

Код свой (у них GPL/LGPL), берём идеи и правила. «Есть» - уже в TotemBots и проверено на стенде.
Поиск пути у нас - mineflayer-pathfinder, он сам сделан по образцу Baritone (A*, стоимость шагов, паркур, лестницы).

## Движение и безопасность (Baritone: PathExecutor, Settings, movements)

| Что | У них | У нас |
|---|---|---|
| Пути, паркур, лестницы и лианы, вода в пути | movements/* | есть (pathfinder) |
| Не ломать и не ставить блоки по дороге | allowBreak / allowPlace | есть (canDig false, без блоков) |
| Высота падения без воды не больше 3 | maxFallHeightNoWater = 3 | **делаем**: maxDropDown 4 → 3 |
| Обходить опасные блоки | blocksToAvoid | **делаем**: огонь, лава, магма, костры, ягодный куст, роза визера, снег-ловушка, кактус |
| Обходить мобов (особенно криперов) | mobAvoidance* | **делаем**: стоимость клеток рядом с криперами |
| Застрял - перестроить путь | movementTimeoutTicks, «too far from path» | **делаем**: сторож: 5 с без продвижения → прыжок/шаг назад и новый путь, 3 раза → сообщить |
| Всплывать в воде, не задыхаться | sprintInWater, allowSwimming | всплытие есть; **делаем**: мало воздуха → вверх |
| Не заходить в запретные места | exclusionAreas (pathfinder) | **делаем**: места из памяти с пометкой «нельзя» (чужие базы) |
| Плавный взгляд | smoothLook, randomLooking | есть (бой, простой); при ходьбе - pathfinder |
| Точки смерти и кровати | doDeathWaypoints, doBedWaypoints | смерть есть; **делаем**: кровать |
| Двери, калитки | traverse | есть (canOpenDoors) |
| Порталы | enterPortal | есть |
| Элитры, постройка по схеме, шахта, разведка | elytra, build, mine, explore | позже, по запросу |
| Карта увиденного (Xaero, кэш чанков Baritone) | cachedChunks | **есть** (`app/worldmap.js`): рельеф по чанкам, постройки игроков (рукотворные блоки у поверхности), сундуки, порталы, кровати, спавнеры, фермы, деревни; по палитрам секций - 30 мс на 169 чанков, бот не замирает; сводка «по карте» в состоянии для Qwen, картинка в панели, деревни и спавнеры - в память |

## Особенности нашего сервера

| Что | Почему | У нас |
|---|---|---|
| Сон: ночь пропускается, когда спят все не-AFK | Essentials `sleep-ignores-afk-players`, бот рядом с хозяином не AFK | **делаем**: кто-то лёг спать, ночь, кровать рядом (16 бл.) → бот ложится; утром встаёт |
| AFK-кика нет | `auto-afk-timeout: -1` | ничего не нужно |
| Античит Vulcan | см. HANDOFF | есть, проверки на стенде |
| Пакеты 26.x | tick_end, окно AuthMe, отбрасывание | есть |

## Не берём

Всё, что обходит античит или правила: Flight, Speed, Blink, Timer, Reach, Velocity(анти-отбрасывание), NoFall,
Jesus, Spider, Step, Nuker, Scaffold, FastBreak, CrystalAura и т.п. Бот играет как обычный клиент.
