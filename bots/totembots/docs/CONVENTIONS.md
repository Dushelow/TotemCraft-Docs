# TotemBots: правила правки кода

## Комментарии и коммиты

- Комментарий у правки — **зачем**, с датой и случаем: `// 23.11: стоял у лестницы и ждал, пока скажут «лезь»`.
  Так через месяц видно, какую жалобу правило лечит, и его не выкинут как лишнее.
- Коммит: `TotemBots: <что меняется для игрока>` + строка соавтора. Пуш сам, после проверки IP (`SPACE.md`).
- Тексты для игрока и журнал — по-русски, без длинных тире.

## Ловушки (каждая уже стоила часов)

1. **Python-правки и обратная косая.** В обычной строке Python `"\b"` — символ «забой», `"\s"` остаётся
   как есть. В JS-регулярке `\b` с кириллицей не работает вовсе. После правки через Python:
   `grep -c $'\x08' app/*.js` должен давать 0; вместо `\b` писать `(?: |$)`.
   Надёжнее: правка через `Write` скрипта на диск, в нём `chr(92)` для обратной косой.
2. **Конфликт имён в примесях.** Все модули — примеси к одному классу `TotemBot`: одинаковое имя метода или
   поля молча перезаписывает чужое. Уже были: `_scene` (features.js), `_opened` (chores.js — Map дверей,
   из-за этого «this._opened.set is not a function» и незакрытые двери), `sceneText`, `placeText`.
   Перед новым именем: `grep -rn "имя" app/`. Брать уникальные (`sceneNow`, `_mechOpened`).
3. **Проверка `quickOrder` отдельно:** вырезать функцию до `\n}\n`, а не по фигурным скобкам — в правилах
   есть `{0,30}`.
4. **Возврат старой версии файла — только через git** (`git show <коммит>:путь > файл`, потом `git checkout HEAD --`).
   Копия «на время» в `/tmp` или блокнот однажды вернула устаревший `bot.js` и сломала выход наружу.
5. **Своя физика бота (prismarine-physics) не всё знает:** люк-лестницу, адские лианы, приседание в воде,
   быстрое плавание, толчок из воды на лианы. Где нужно — поправка скорости в тике `nav.js`, осторожно с
   античитом (не быстрее игрока).
6. **Порядок тиков:** пачки `bot.on('physicsTick')` выполняются в порядке подключения; поправка
   управления должна стоять после того, кто жмёт клавиши (pathfinder).
7. **Правило «один раз сработало — сломало другое».** Любая правка лестниц, люков, воды, механизмов — прогнать
   выход из секретной комнаты (3 раза) и стенды навигации, см. `STANDS.md`.
8. **Не чинить по описанию.** Владелец может ошибиться в координатах и названиях («камень»), бот — тоже.
   Опора — журнал движения и копия места (`area.*.json`).

## Где что писать

- Новая команда для нейросети — `commands.js` (имя, синонимы, аргументы, описание, разбор в `act`) и `case` в
  `bot.run()`.
- Короткая фраза хозяина без нейросети — `quickOrder()` в `brain.js`.
- Правило для нейросети — строки подсказки в `brain.js` (рядом с «Поле отмечай remember…»).
- Новый навык тела — метод в `bot.js` или своя примесь (добавить в список примесей в конце `bot.js`).
