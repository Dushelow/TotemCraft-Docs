# TotemBots: стенды и журналы

Все команды — из папки `bots/totembots`, в Git Bash (у владельца — PowerShell, там `;` вместо `&&`).

## Без сервера (секунды, гонять после любой правки `nav.js`)

```bash
node test/shaft_test.js        # лазы с люками: вниз 3 из 3 (вверх в двух лазах - известный недоход)
node test/structures_test.js   # 16 построек туда-обратно: должно быть 28 из 28
node test/fuzz_nav.js 150      # 150 случайных миров: 0 «физика не прошла»
node test/navgraph_test.js     # карта связей и дороги: 7 из 7
```

Мир в памяти и проверка физикой игры — `test/navlib.js`. Механизмы (поршни, кнопки) этот стенд не двигает.

## С сервером: tc-up (копия мира владельца)

Docker-сервер Purpur 26.3 с плагинами боевого (Vulcan, AuthMe...), порт 25566, папка
`testbed/upgrade` пространства (вне репозитория). Подробно о стенде — `testbed/README.md` пространства.

- Docker Desktop после перезагрузки компьютера выключен — запустить его, потом `docker start tc-up` и ждать
  `healthy`.
- Плагин плановой перезагрузки гасит стенд в 04:30 — снова `docker start tc-up`.
- Копия мира: мод simple-world-downloader у владельца пишет в папку
  `%APPDATA%\.tlauncher\legacy\Minecraft\game\saves\redstone_test` (не в «play.totemcraft.net»!).
  Перенести: остановить `tc-up`, скопировать `dimensions/minecraft/overworld/{region,entities,poi}/r.*.mca`
  в `testbed/upgrade/mc/2025/dimensions/minecraft/overworld/...` (старые — в `testbed/upgrade/save/`),
  запустить. Мод может сохранить отдельные блоки не так, как в игре — сверять с владельцем.
- Сломал блок на стенде своей проверкой — вернуть файл региона из копии, а не `setblock` наугад.

### Сценарий `test/secret_room_test.js`

Настоящий бот `TbAlex` в копии мира. Аргументы — точка старта `x y z` (по умолчанию 205 50 −579).
Переменные: `ACT` — действия JSON (по умолчанию «выйти наружу»), `BACK=1` — потом назад своим путём,
`OBST="x y z"` — второй игрок стоит на пути, `BOAT=1` — лодка под ботом, `TB_DEBUG_BACK=1` — подробный журнал.

```bash
node test/secret_room_test.js 204 50 -579                                   # выход из секретной комнаты
ACT='[{"act":"goto","x":204,"y":50,"z":-579}]' node test/secret_room_test.js 216 71 -577   # вход снаружи
ACT='[{"act":"swim","seconds":3},{"act":"back"}]' node test/secret_room_test.js 339 67 -772  # корабль: в воду и назад
```

Места в копии: секретная комната 204 50 −579; дверь с плитой 207/208 50 −579; столб лестницы 209 51..67;
люк 209 68; кнопка 210 69 −579; стена на поршнях 211 71..72 −579; плита в канале 212 71 −579; ямка 215 69.
Корабль: палуба ~339 67 −772, лианы 342 −772 и 342 −782 (63..68), трюм 330 63 −776.

## Журналы (разбор жалобы)

У установленной программы — `%APPDATA%\TotemBots\logs`, из исходников — `local/logs`. Время в них UTC
(МСК = +3).

| Файл | Что |
|---|---|
| `<бот>.log` | всё: приказы, ответы мозга (`←`), итоги, застревания с разбором клеток вокруг |
| `<бот>.qwen.log` | что ушло нейросети и что она ответила |
| `<бот>.move.log` | последние 60 с движения, 4 раза в секунду: место, клавиши, вода, цель, путь, срез мира |
| `<бот>.move.<время>.log` | снимок движения в момент застревания, смерти, «пути нет» (последние 10) |
| `area.<время>.json` | копия блоков 33×37×33 вокруг при неудаче (не дошёл, застрял, не вышел) — для стенда |
| `login.log` | ход входа на сайты нейросетей через браузер |

Античит — только на сервере: `ssh` по ключу, `zgrep -a "Loki" /home/minecraft/server/logs/<дата>*.log.gz | grep Vulcan`.

Порядок разбора: найти в `<бот>.log` фразу хозяина по времени → что ответил мозг (`←`) → итог и ошибки →
`move.<время>.log` и `area.*.json` для места → воспроизвести на стенде → чинить.
