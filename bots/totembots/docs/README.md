# TotemBots: карта документации

Программа для компьютера (Electron): боты-игроки Minecraft на mineflayer. «Мозг» — нейросеть через сайт
(Qwen, DeepSeek и др.) или по ключу, «тело» — код бота, который ходит, плавает, лезет, дерётся и делает
дела сам. Работает с любым сервером; у владельца — TotemCraft (Purpur 26.3, ViaVersion, Vulcan, AuthMe).

## С чего начинать

| Документ | Что в нём |
|---|---|
| `../CLAUDE.md` | правила работы: начало и конец сессии, что нельзя ломать |
| `STATUS.md` | что работает, что нет, открытые задачи, последние проверки, античит |
| `CONVENTIONS.md` | как править код (ловушки, которые уже стоили часов), коммиты |
| `ARCHITECTURE.md` | как устроено: окно, мозг, тело, навигация, поток приказа |
| `PROJECT_STRUCTURE.md` | что в каком файле (`app/*.js`, `test/*.js`) |
| `STANDS.md` | стенды и журналы: как проверить и как разобрать жалобу |

день. Текущее состояние — только в `STATUS.md`.

## Как поддерживать

| Что поменялось | Какой документ поправить |
|---|---|
| починено или найдено новое | `STATUS.md` |
| новый или удалённый файл в `app/` или `test/` | `PROJECT_STRUCTURE.md` |
| новый навык, команда, путь приказа | `ARCHITECTURE.md` |
| новый стенд, сценарий, переменная | `STANDS.md` |
| новая ловушка при правке кода | `CONVENTIONS.md` |

После правки документов: `sh scripts/check_docs.sh` (из папки `bots/totembots`).
