# TotemBots: устройство

## Окно (Electron)

`app/main.js` — окно: слева панель (`panel.html`, `panel.js`, `panel-preload.js`), справа окна сайтов нейросетей
(WebContentsView, у каждого сайта своя сессия `persist:<сайт>`). Данные: у установленной программы
`%APPDATA%\TotemBots` (`config.json`, `logs/`, `memory/`, `map/`), из исходников — `local/`. Путь передаётся
модулям через `process.env.TOTEMBOTS_LOCAL`.

Первый запуск — мастер в панели (сервер, ник хозяина, бот, пароль, версия); окна сайтов спрятаны, пока он не
заполнен. Вход на сайты через Google — `chrome-login.js`: Chrome по CDP, иначе Firefox в два шага (обычное
окно для входа, потом скрыто по WebDriver BiDi забрать куки; user agent сайта = браузера входа, иначе сайт
выкидывает). Ход входа пишется в `logs/login.log`.

## Мозг

`brain.js` собирает события игры и приказы в сообщение для нейросети: строки `[чат]`, `[итог]`, `[событие]`,
состояние (`stateFor`: инвентарь, что вижу, `[место сейчас]` из `scene.js`, зоны, память). Ответ — JSON
`{say, actions, channel, to, thought}`; действия разбираются из `commands.js` (`!команда(аргументы)`).

`router.js` — несколько мозгов по порядку из настроек; при лимите или ошибке — следующий, капча — ждать до
3 мин в том же. Сайты — `web-chat.js` (DeepSeek и др.), Qwen — `qwen-bridge.js`; новый чат сайта получает
вводную и последние события.

Защиты в мозге: устаревший ответ (хозяин уже написал новое) выбрасывается не больше раза подряд; чужие говорят
между собой — бот молчит; хозяин сказал «пиши в клан / рядом» — `chatPref`.

## Поток приказа

1. **Быстрые команды** — `quickOrder()` в `brain.js`: короткие фразы хозяина тело выполняет сразу, без
   нейросети («за мной», «ко мне», «стой», «лезь наверх», «выйди в город, подожди и вернись», «в воду»,
   «вылезай», «в портал», «защищай/спасай/нападай», «прими инвайт» → `/accept`, урожай, торговля, зоны).
2. Иначе — нейросеть; её действия выполняет `bot.run()` (большой `switch (a.act)` в `bot.js`).
3. Итог (`[итог] ...`) уходит обратно в мозг; ошибки — простыми словами.

## Тело

`bot.js` — класс `TotemBot` (mineflayer). Остальные модули — примеси (mixins) к нему: список в конце `bot.js`
(`for (const M of [require('./scene').Scene, require('./vehicles').Vehicles, ...])`). Имена методов и полей
примесей общие на весь класс — см. `CONVENTIONS.md` про конфликты имён.

Тики тела (без нейросети): еда, защита (`guard.js`), компаньон (`companion.js`, занятия рядом с хозяином —
только на его ярусе), присутствие (`presence.js`: кормить хозяина), метки (`marks.js`), понимание места
(`scene.js`), вода (`water.js`, `swim.js`), застревание (в `bot.js`: шаг вбок у забора, рывок в воде, механизм).

Ключевые навыки тела:
- `goto` (в `bot.js`): поиск пути + повторы; «пути нет» → лестница рядом до высоты цели → механизм у входа;
  «почти дошёл» → механизм; заранее, если путь целиком не строится, — механизм у входа (кроме шагов навыков).
- `climbLadder` — лестницы и лианы: к столбу (до 24 бл.), лезть с прыжком, держаться середины, люки — только
  закрытые и только если вбок некуда, выход вбок/в сторону стены, стоп на высоте цели (`stopY`, хозяин выше).
- `useMechanism` — кнопки, рычаги, плиты у дверей и поршней (не у люков); плита в воде — подход по дну и нырок;
  после нажатия — снимок блоков, `intoOpening` бежит в открывшийся проход. Лимит 4 в минуту.
- `goOutside` — наружу под небо по раундам (выход по целому пути → лестница → механизм), запись своего пути;
  `goSwim` — в открытую воду (сначала край, с которого спрыгнуть); `walkBack` — назад тем же путём.
- `walkTrail` — следом за хозяином по его следу, когда к нему нет пути.

## Навигация

`nav.js` ставится в `Movements` mineflayer-pathfinder: проходимость по настоящей форме блоков и свои ходы —
люки (`hatches`: вниз с соседней клетки, вверх через люк посреди лаза), спуск в столб лестницы, сход с лестницы
вбок на любой высоте, прыжок в воду с высоты, мягкие приземления (слизь, сено, мёд, рыхлый снег), водяные лифты
(пузыри), плавание (`swimMoves`), паркур с проверкой физикой. Тики `nav.js`: двери (открыть/закрыть за собой,
двери на плите не трогать рукой), спуск без «вперёд», лезть с прыжком, лианы ада и люк-лестница (своя физика их не
знает), гребок в воде против течения, бег выключен во время еды.

## Следование

Режим `follow` в `bot.js`: `GoalFollow`; хозяин пропал у портала — за ним в портал; место из другого мира не
искать; путь «частичный» → сначала механизм у входа, потом его след (`walkTrail`).

## Понимание места

`scene.js` (`sceneNow`, `sceneNowText`): внутри/снаружи, корабль/пещера/постройка, выходы (двери, люки,
лестницы, проёмы под небо), края к воде. Сводка идёт мозгу строкой `[место сейчас]`; тело использует край к воде
(`goSwim`) и проёмы (`goOutside`).
