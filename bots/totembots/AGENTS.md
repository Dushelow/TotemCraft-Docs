# Что берём из проектов, где нейросеть сама играет в Minecraft (сверка 15.11.2026)

Источники: Mindcraft (github.com/mindcraft-bots/mindcraft, arXiv 2504.17950), Voyager (github.com/MineDojo/Voyager,
arXiv 2305.16291), Project Sid / PIANO (github.com/altera-al/project-sid, arXiv 2411.00114), GITM (github.com/OpenGVLab/GITM,
arXiv 2305.17144), Optimus-1 и JARVIS-1 (arXiv 2408.03615). Код свой, берём идеи.

Общая мысль у всех: нейросеть решает крупное (цель, план, разговор), а мелкое тело делает само и быстро; нейросеть
знает мир (рецепты, что из чего), помнит свой опыт (что вышло, что нет) и сама себе ставит следующие задачи.

| Идея | Где | У нас | Делаем |
|---|---|---|---|
| Команды прямо в речи, синонимы, список при ошибке | Mindcraft (!commands) | **есть** (`commands.js`, 15.11) | - |
| Рефлексы тела без нейросети: не утонуть, не сгореть, не стоять в лаве, выбраться при застревании, подобрать вещи, отойти, если игрок вплотную, факел в темноте | Mindcraft modes (self_preservation, unstuck, item_collecting, elbow_room, torch_placing, idle_staring) | частично: всплыть, выйти на берег, бой, еда, броня, подобрать после смерти, сторож застревания | **да**: огонь/лава - выйти, мало здоровья - отступить, отойти от игрока вплотную, подбирать выпавшее рядом всегда, факел в темноте |
| Цель и самоподгонка: пока цель не достигнута, мозг сам гонит шаги без ожидания | Mindcraft self-prompting (!goal) | частично: цель есть, до 8 своих дел подряд | **да**: с целью - цикл без пауз до !endGoal или 3 неудач подряд; игрок может перебить |
| Знание мира: что из чего крафтится, полный план «что нужно для железной кирки» | GITM (текстовые знания), Mindcraft !getCraftingPlan / !craftable | нет: при нехватке говорим только чего не хватает на один шаг | **да**: `!plan(предмет)` - дерево рецептов из реестра игры с учётом инвентаря; `!craftable` - что могу сделать сейчас |
| Опыт: что вышло и что нет, уроки | Voyager (библиотека удачных навыков), Optimus-1 (сжатый опыт + рефлексия) | память неудач на 20 мин, дневник | **да**: «уроки» в памяти (`!lesson`), удачные цепочки команд сохраняются как навык с именем и повторяются одной командой |
| Автоучебник: следующая задача по состоянию (инвентарь, что умею, что не вышло) | Voyager automatic curriculum | открытое «свободное время» | **да**: в свободное время - список «сделано / не вышло / есть в инвентаре», чтобы задачи росли (дерево -> кирка -> камень -> печь -> железо) |
| Нейросеть пишет свой код навыка (JS) | Mindcraft !newAction, Voyager | нет | **позже и осторожно**: код исполняется на компьютере владельца; только в песочнице с доступом к телу бота, без файлов и сети |
| Параллельные потоки: разговор не ждёт дела и наоборот; модуль социального понимания | Project Sid PIANO (concurrency + coherence, social awareness) | разговор и дела уже идут параллельно; люди в памяти | **да**: отношения к людям (друг, просил, обидел) в памяти людей |
| Несколько ботов договариваются между собой | Mindcraft MineCollab | один бот | позже |
| Зрение: снимок экрана в мультимодальную модель | Mindcraft (vision), JARVIS-1, Optimus-1 | текстовое [вижу] | позже: Qwen мультимодальный, можно слать картинку из prismarine-viewer |
| Скорость ответа нейросети | все - через API | сайт Qwen, 5-10 с на решение | ждём решения владельца про API |

Порядок работ: рефлексы -> план крафта (!plan, !craftable) -> цикл цели -> уроки и навыки -> автоучебник -> отношения.
Каждое - с проверкой на стенде-копии мира (`test/walk_test.js` и новые сценарии).
