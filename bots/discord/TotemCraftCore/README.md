# TotemCraftCore

Программа работает под ботом Discord «TotemCraft | Core», служба на VPS `totemcraftcore`.

Бот-помощник Discord-сервера TotemCraft. Заменяет закрывшуюся Лакуну (последняя запись в журнале 31.08.2026). Поведение повторяет то, что Лакуна делала на сервере по её журналу с 27.02 по 31.08.2026.

## Что делает

1. **Роли по галочке.** Реакция ✅ в «⭐┃регистрация» выдаёт роли Verified и «Игрок сервера». Снятие реакции роли не забирает.
2. **Журнал** в «📒┃логи-дискорда»: сообщения (изменено, удалено, массовое удаление), ветки (создана, удалена, переименована), каналы (создан, удалён, изменён), роли участников (добавлена, убрана), роли сервера (создана, изменена, удалена), баны и муты (выдан, снят), смена ника на сервере и имени пользователя. Изменения каналов ботами не пишутся: «Игровой чат» каждые 10 минут меняет описание minecraft-чата. Сдвиги позиций каналов и ролей тоже не пишутся.
3. **Голосовые комнаты.** Заход в «🔊┃войсчат» создаёт канал `🏠┃#N - комната игрока <ник>` в «Голосовые каналы» и переносит туда игрока. Хозяин может переименовать комнату, поставить лимит и выгнать человека. Пустая комната удаляется. Если у игрока уже есть комната, его возвращают в неё.
4. **Галерея.** Под постом с картинкой или ссылкой создаётся тред с названием по первой строке подписи (без подписи: «Комментарии») и ставится 👍.
5. **Ивенты.** Под анонсом в «🎯┃ивенты» создаётся тред с названием по первой строке анонса.

6. **Ящик задач для Claude.** Команды `/dushelow`, `/totemcraft`, `/adminbot` (одно и то же) с полем «задача». Видны только тем, у кого есть право «Отправка в тайм-аут», писать могут модератор и выше и владелец сервера, работают только в «⚡┃админ-чат». Задача записывается в таблицу `inbox` базы бота, бот отвечает «📥 Задача #N записана». Сам бот задачи не выполняет: их разбирает Claude на утреннем и вечернем обходе и отвечает в админ-чат.

Текст удалённого сообщения бот берёт из своей памяти (SQLite), поэтому видит только сообщения, написанные после запуска, и не старше `MESSAGE_KEEP_DAYS` дней (по умолчанию 30).

## Права бота

Работает под ботом «TotemCraft | Core» (права Administrator). Если когда-нибудь вынести на отдельное приложение, ему хватит:
View Channels, Send Messages, Embed Links, Read Message History, Add Reactions, Create Public Threads, Send Messages in Threads, Manage Roles, Manage Channels, Move Members, View Audit Log.
Privileged intents: Server Members, Message Content.

Роль бота должна стоять выше ролей Verified и «Игрок сервера», иначе Дискорд не даст их выдать.

## Настройка

Номера каналов и ролей в `.env.example`. Токен только в `/home/totemcraftcore/.env`, в репозиторий не коммитится.

## Тесты

```
python -m unittest discover -s tests -v
```

Тесты проверяют логику без подключения к Дискорду: названия тредов и комнат, номера комнат, разбор изменений, память сообщений.

Логика тредов «по первой строке» и комнат «#N - комната игрока» повторяет то, что было видно в журнале Лакуны; код Лакуны (github.com/LacunaHub/LacunaBot, AGPL-3.0) не использовался.
